Kalıtım Nedir?

👑 Ata (Base / Super)

Temel/üst sınıf. Kendisinden yeni sınıflar türetilir; ortak davranışı taşır.
SayacButonu

🧬 Çocuk (Derived / Sub)

Atadan türeyen sınıf. Her şeyi devralır + kendi farkını ekler.
KirmiziButon

🔗 "is-a" İlişkisi

KirmiziButon bir SayacButonu'dur; o da bir QPushButton'dur.

Ata için base / super / üst sınıf / ata; çocuk için derived / sub / alt sınıf / çocuk — hepsi aynı şey.

Kurucu · 1/2

__init__ Yazmazsan Ne Olur?

class BenimButonum(QPushButton):
    pass                       # __init__ YOK

b = BenimButonum("Kaydet")     # QPushButton'ın kurucusu çalışır
b.text()                       # 'Kaydet'

class KirmiziButon(SayacButonu):
    pass                       # __init__ YOK

k = KirmiziButon()             # SayacButonu'nun kurucusu çalışır
k.sayac, k.text()              # (0, 'Tıkla (0)')

Çocukta __init__ yoksa Python atanınkini kullanır — atanın parametreleriyle birlikte ("Kaydet"). Bedavaya kurucu!

Bu yüzden basit türetmelerde pass yeter.

Kurucu · 2/2

Kendi __init__'in Varsa: super()

class RenkliSayac(SayacButonu):
    def __init__(self, renk):
        super().__init__()           # 1) önce ata kursun
        self.setStyleSheet(f"background:{renk}")  # 2) sonra farkın

kirmizi = RenkliSayac("#ef4444")
mavi    = RenkliSayac("#3b82f6")     # tek sınıf, her renk

Kendi __init__'ini yazınca atanınki otomatik çalışmaz — onu sen super().__init__() ile çağırırsın.

Unutursan Qt hemen RuntimeError verir. (Detay: Hafta 3)

Slayt 4'te her renk ayrı bir sınıftı; şimdi tek sınıf + parametre. Ortak iş atada (SayacButonu), fark kurucuda.

Kendi Widget'ımız · 1/3

Kendi Sayaç Butonumuz

class SayacButonu(QPushButton):     # QPushButton'dan TÜRE
    def __init__(self):
        super().__init__()          # atanın kurucusu (şart!)
        self.sayac = 0              # KENDİ eklediğimiz durum
        self.clicked.connect(self.artir)  # devralınan sinyal
        self.guncelle()

    def artir(self):                # KENDİ davranışımız
        self.sayac += 1
        self.guncelle()

    def guncelle(self):
        self.setText(f"Tıkla ({self.sayac})")  # devralınan metot

Daha Şık · Bonus

Aynı Buton, Daha Zarif: property

Yukarıdaki hâli de doğru. Ama Python'da @property ile daha şık olur: atama, arayüzü kendiliğinden günceller.

class SayacButonu(QPushButton):
    def __init__(self):
        super().__init__()
        self.sayac = 0                  # setter çağrılır → metni de kurar
        self.clicked.connect(self.artir)

    @property
    def sayac(self):                    # GETTER (okuma)
        return self._sayac

    @sayac.setter
    def sayac(self, deger):             # SETTER (yazma)
        self._sayac = deger
        self.setText(f"Tıkla ({deger})")  # arayüzü güncelle

    def artir(self):
        self.sayac += 1                 # setter halleder

Getter @property → btn.sayac okunurken çalışır.

Setter @sayac.setter → atama, arayüzü kendisi günceller.

✅ guncelle() gerekmez — daha temiz kapsülleme.

Kanıt

Gerçekten bir QPushButton mu?

btn = SayacButonu()

isinstance(btn, QPushButton)   # True   ← "is-a" !

isinstance(nesne, Sınıf) → bu nesne o türden mi?  issubclass(A, B) → A sınıfı B'den mi türedi? İkisi de kalıtım zincirine bakar. Bu yüzden SayacButonu'nu bir QPushButton beklenen her yere koyabilirsin.

Dikkat

Sık Yapılan Hatalar

😱 super() unutmak

Kendi __init__'inde super().__init__() çağırmamak → Qt RuntimeError verir, widget kurulmaz.

🫥 Metni kurmamak

__init__'te setText() yoksa buton ilk tıklamaya kadar boş ve minicik (47×22 px) açılır — "buton nerede?" diye arama.

🔀 is-a / has-a karıştırmak

"Sahip olma"yı kalıtımla çözmeye çalışmak: Panel bir buton değildir, butonları vardır.

✏️ Atayı bozmak

Çocuğa özel bir şeyi (ör. kırmızı rengi) ata sınıfa yazmak → tüm kardeşler kırmızı olur.

Kural: ortak olan ataya, farklı olan çocuğa.

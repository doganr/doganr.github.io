super() nedir?

super(), bir sınıfın atasına (üst sınıfına) erişmenin yoludur. "Bu işi atam nasıl yapıyordu, ona sor" demektir.

class SayacButonu(QPushButton):
    def __init__(self):
        super().__init__()      # QPushButton kurucusu
        self.sayac = 0          # sonra kendi işini yap

Bunu Hafta 1'den beri yazıyorduk — artık ne yaptığını tam biliyoruz.

Altında Ne Var?

super() Aynı Nesne, Üst Sınıf Gözüyle

🎯 Aynı self

super() yeni bir nesne oluşturmaz; aynı nesnenin ata sürümüne bakar.

⛓️ Zincirde bir sonraki

Atanın metodunu bulup çalıştırır — MRO zincirinde bir üst durak.

🚫 İsim yazmaz

QPushButton.__init__(self) yerine super() — ata değişse bile çalışır.

super().artir() = "aynı ben, ama atamın artir'ını çalıştır."

Kurucu · 1/2

Neden super().__init__() Şart?

class SayacButonu(QPushButton):
    def __init__(self):
        self.sayac = 0        # 💥 super() UNUTULDU
        self.setText("Tıkla") # RuntimeError: base __init__ çağrılmadı

Kendi __init__'ini yazan çocuk, ilk iş super().__init__() çağırmalı — yoksa QPushButton'ın altyapısı hiç kurulmaz.

Sonuç: RuntimeError ya da yarım/garip davranan bir widget.

Kurucu · 2/2

Ataya Argüman Geçirmek

class Hayvan:
    def __init__(self, ad):
        self.ad = ad

class Kedi(Hayvan):
    def __init__(self, ad, renk):
        super().__init__(ad)     # ad'ı ataya GEÇİR (o kursun)
        self.renk = renk         # kalanı kendin

k = Kedi("Tekir", "sarı")        # k.ad="Tekir", k.renk="sarı"

Ata bir argüman bekliyorsa (ad), onu super().__init__(ad) ile iletirsin.

İş bölümü: ortak kısmı ata kurar, farkı çocuk ekler.

Metot Ezme (Override)

🧬 Devralma

Çocuk, atanın metodunu olduğu gibi kullanır.

✍️ Ezme (Override)

Çocuk, aynı isimli metodu yeniden tanımlar → kendi sürümü çalışır, atanınki gölgelenir.

Aynı isim, farklı gövde. Çocuğun sürümü atanınkinin yerini alır (o nesne için).

Python Nasıl Seçer

Önce Çocuğa Bakar

class Ata:
    def selam(self): print("Ata selamı")
class Cocuk(Ata):
    def selam(self): print("Çocuk selamı")   # aynı isim → EZME

Cocuk().selam()   # "Çocuk selamı"  (önce çocuğa bakar)
Ata().selam()     # "Ata selamı"    (ata değişmedi)

Python metodu nesnenin sınıfından başlayıp yukarı doğru arar. İlk bulduğunu çalıştırır.

Çocukta varsa → çocuğunki. Ezme budur.

Örnek · 1/2

Butona Renk Davranışı Ekle

class RenkliButon(SayacButonu):     # SayacButonu'ndan türe
    def artir(self):                # aynı isim → EZME (override)
        super().artir()             # önce atanın işi: say + güncelle
        if self.sayac >= 5:         # sonra KENDİ eklememiz:
            self.setStyleSheet("background:#ef4444")  # kırmızıya dön

Ezme mi, Genişletme mi?

🔁 Tamamen Değiştir

def artir(self):
    self.setText("değişti")   # atanınki YOK sayıldı

super() çağırmazsan atanın davranışı kaybolur.

➕ Koru + Ekle (genişlet)

def artir(self):
    super().artir()    # atanınki +
    self.renklendir()  # kendi eklemen

super() ile atanın işini korur, üstüne eklersin.

En sık kalıp: metodu ez, içinde super() çağır, sonra kendi farkını ekle.

super() İle mi, Olmadan mı? · Canlı İki butona da bas — farkı gör

        self.kirmizi()

MRO'yu Kendi Gözünle Gör

RenkliButon.mro()
# [RenkliButon, SayacButonu, QPushButton,

Sınıf.mro() (ya da Sınıf.__mro__) o sınıfın arama sırasını liste olarak verir.

En sonda hep object vardır. (Araya bazı Qt iç sınıfları da girer; kısalttık.)

İki Ata

Çoklu Kalıtım

class Ucan:
    def hareket(self): print("uçar")

class Yuzen:
    def hareket(self): print("yüzer")

class DenizUcagi(Ucan, Yuzen):   # iki atadan
    pass

DenizUcagi().hareket()   # uçar (soldan sağa)

Bir sınıf birden çok atadan türeyebilir. Çakışma olursa MRO karar verir — soldaki önce gelir.

class C(A, B): önce A'ya bakılır.

Pratik Kullanım

Mixin: Yetenek Ekleme Sınıfı

class LoglamaMixin:              # yalnız yetenek katar
    def logla(self):
        print(self.text(), "tıklandı")

class LoglayanButon(LoglamaMixin, SayacButonu):
    def artir(self):
        super().artir()         # atanın işi
        self.logla()            # mixin yeteneği

Mixin = tek başına anlamlı olmayan, başka sınıflara yetenek katan küçük sınıf.

Qt uygulamalarında sık kullanılır (loglama, kaydetme…).

Gerçek Güç

Qt'nin Kendi Metotlarını Ez

class SayacButonu(QPushButton):
    def mousePressEvent(self, olay):    # Qt metodunu EZ
        print("basıldı!")               # kendi eklemen
        super().mousePressEvent(olay)   # Qt'nin işini de yap

Override'ın asıl gücü: Qt'nin hazır olay metotlarını (fare, tuş, çizim) ezip kendi davranışını eklemek.

Yine kural: super() çağır ki Qt'nin normal işleyişi bozulmasın.

Sık Yapılan Hatalar

😱 super() unutmak

Override'da atanın işini istemeden silmek — sayma/çizim kaybolur.

♾️ self.metot() çağırmak

Override içinde super() yerine self.artir() → sonsuz döngü (kendini çağırır).

🔤 İsim tutmaması

Ezmek istediğin metodun adını yanlış yazmak → ezme olmaz, yeni bir metot doğar.

Kural: ataya erişmek için her zaman super(), asla self.

Ders Sonu Uygulama · Proje

Proje: Akıllı Buton Ailesi

Geçen haftaki SayacButonu'nu ezerek farklı davranan üç buton türet ve bir panele diz.

class SayacButonu(QPushButton):   # geçen hafta
    def __init__(self):
        super().__init__()
        self.sayac = 0
        self.clicked.connect(self.artir)
        self.setText("Tıkla (0)")
    def artir(self):
        self.sayac += 1
        self.setText(f"Tıkla ({self.sayac})")

# Görev: artir()'ı ezerek 3 farklı buton yap.

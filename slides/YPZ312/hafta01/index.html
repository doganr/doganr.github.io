import torch
x = torch.arange(12, dtype=torch.float32)   # [0., 1., ..., 11.]

x.numel()          # 12   ·   x.shape → torch.Size([12])

X = x.reshape(3, 4)                 # 3×4 matris
torch.zeros((2,3)); torch.ones((2,3)); torch.randn(3, 4)   # hazır tensörler

shape = boyutlar, numel = eleman sayısı. NumPy'da birebir: np.arange, reshape.

İndeksleme

Eriş, Dilimle, Ata

X = torch.arange(12).reshape(3, 4)

X[-1]          # son satır      → [8, 9, 10, 11]
X[1:3]         # 1. ve 2. satır

X[1, 2] = 17           # tek elemanı değiştir
X[0:2, :] = 12         # ilk iki satırın tümü = 12

Python gibi 0-tabanlı; a:b aralığı b hariç. : "tüm o eksen" demek.

Dilime atama yapabilirsin — tek seferde bir bloğu güncelle.

Negatif indeks sondan sayar: X[-1] son satır, X[:, -1] son sütun.

İşlemler

Eleman-Eleman & Birleştirme

x = torch.tensor([1., 2, 4, 8])
y = torch.tensor([2., 2, 2, 2])
x + y,  x - y,  x * y,  x / y,  x ** y   # hepsi eleman-eleman

torch.exp(x)                    # e^x  (eleman-eleman)
torch.cat((X, Y), dim=0)        # alt alta birleştir (satır)
X == Y                          # eleman-eleman karşılaştırma → bool

Standart işlemler (+ - * / **) aynı şekilli tensörlerde eleman-eleman çalışır.

cat ile eksende birleştir; == ile maske üret; X.sum() ile topla.

Kural: döngü değil, tüm tensör üstünde tek işlem düşün — birazdan bunun hız demek olduğunu ölçeceğiz.

Bellek & Dönüşüm

Yerinde İşlem & NumPy ↔ Torch

before = id(Y)
Y = Y + X;   id(Y) == before   # False → yeni bellek!

Z = torch.zeros_like(Y);  Z[:] = X + Y   # yerinde yaz
X += Y                                    # yerinde (bellek dostu)
A = X.numpy()            # Torch → NumPy
B = torch.from_numpy(A)  # NumPy → Torch

a = torch.tensor([3.5])
a.item(), float(a), int(a)   # 1-elemanlı → Python sayısı

Büyük tensörlerde yerinde işlem (+=, [:]) gereksiz kopya üretmez. NumPy ile dönüşüm bedava (bellek paylaşılır).

Hazırla & Çevir

Eksiği Doldur, Tensöre Çevir

X = pd.get_dummies(X, dummy_na=True)   # kategorik → 0/1 sütun
X = X.fillna(X.mean())                 # sayısal eksik → ortalama

X = torch.tensor(X.values, dtype=torch.float32)   # tabloyu tensöre
y = torch.tensor(y.values, dtype=torch.float32)

get_dummies: "Arduvaz/NaN" gibi kategoriyi ayrı 0/1 sütunlara böler (one-hot).

fillna(mean): sayısal boşlukları ortalamayla doldurur. Artık her şey sayı → tensör.

Kural: model yalnız sayı anlar. Ön işleme = veriyi eksiksiz sayısal tensöre çevirmek.

Lineer Cebir

Skaler → Vektör → Matris

\[ x\in\mathbb{R}, \quad \mathbf{x}\in\mathbb{R}^{n}, \quad \mathbf{A}\in\mathbb{R}^{m\times n} \] 
x = torch.tensor(3.0)               # skaler
v = torch.arange(4)                 # vektör  (uzunluk 4)
A = torch.arange(6).reshape(3, 2)   # matris  (3×2)

A.T                                 # devrik (transpose) → 2×3

Vektör = bir eksen, matris = iki eksen, tensör = n eksen. Devrik satır↔sütun takas eder.

Bir örnek genelde bir vektör; bir veri kümesi (batch) bir matris; bir grup görüntü bir 4B tensör.

Aritmetik

Hadamard Çarpımı (eleman-eleman)

\[ (\mathbf{A}\odot\mathbf{B})_{ij} = A_{ij}\,B_{ij} \] \[ \begin{bmatrix}1&2\\3&4\end{bmatrix}\odot\begin{bmatrix}2&0\\1&3\end{bmatrix} = \begin{bmatrix}2&0\\3&12\end{bmatrix} \] 
A * B        # Hadamard: eleman-eleman çarpım
A + 2        # her elemana skaler ekle
A * 2        # her elemanı ölçekle

Dikkat: A * B (Hadamard) ≠ A @ B (matris çarpımı). İlki eleman-eleman, ikincisi satır×sütun.

İndirgeme

Topla, Ortala, Eksen Seç

\[ \sum_{i} x_i, \qquad \bar{x} = \frac{1}{n}\sum_{i} x_i \] 
A.sum(), A.mean()          # tüm elemanlar

A.sum(axis=0)              # sütun toplamları (satırları yok et)
A.sum(axis=1, keepdims=True)   # boyut korunur → broadcast'e hazır

A.cumsum(axis=0)           # kümülatif toplam (indirgemez)

axis=0 satırlar boyunca toplar → sütun sonucu. keepdims ekseni 1 olarak tutar.

Normalizasyonda sık kalıp: A / A.sum(axis=1, keepdims=True) — keepdims sayesinde broadcast çalışır.

Sayısal Örnek

İndirgeme — Somut Sayılar

\[ A=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix} \]
\[ \text{sum(axis=0)}=\begin{bmatrix}5&7&9\end{bmatrix} \] sütunları topla ↓   (1+4, 2+5, 3+6)
\[ \text{sum(axis=1)}=\begin{bmatrix}6\\15\end{bmatrix} \] satırları topla →   (1+2+3, 4+5+6)

axis=0 → sütun toplamı, axis=1 → satır toplamı · ayrıca sum()=21, mean()=3.5.

Nokta Çarpım

Nokta Çarpım: Bir Nöronun Çekirdeği

\[ \mathbf{x}^\top \mathbf{y} = \sum_{i} x_i y_i \] 
x = torch.tensor([1., 2., 3.])
w = torch.tensor([0.5, -1., 2.])

torch.dot(w, x)          # 0.5 - 2 + 6 = 4.5
torch.sum(w * x)         # aynı sonuç

Ağırlıklı toplam = nokta çarpım. Nöronun w·x + b ifadesinin ilk yarısı.

Tek nöron bir nokta çarpım; bir katman bunun yüzlercesi → matris çarpımı.

Çarpımlar

Katman = Matris Çarpımı

\[ (\mathbf{A}\mathbf{B})_{ij} = \sum_k A_{ik}B_{kj} \] 
torch.mv(A, x)      # matris-vektör  (A:3×2, x:2) → 3
torch.mm(A, B)      # matris-matris  (A:3×2, B:2×5) → 3×5

A @ B               # aynısının kısa yolu (NumPy'da da: A @ B)

İç boyutlar uyuşmalı: (m×k)·(k×n) → m×n. Bir ağın tüm işi bu çarpımlara iner.

İyi haber: matris çarpımı utanç verecek kadar paralel — sıradaki slaytta ölçüyoruz.

Sayısal Örnek

Matris Çarpımı — Adım Adım

\[ \begin{bmatrix}{\color{#f87171}1}&{\color{#f87171}2}&{\color{#f87171}3}\\4&5&6\end{bmatrix} \begin{bmatrix}{\color{#34d399}1}&0\\{\color{#34d399}0}&1\\{\color{#34d399}1}&1\end{bmatrix} = \begin{bmatrix}{\color{#fbbf24}4}&5\\10&11\end{bmatrix} \]
\[ {\color{#fbbf24}C_{11}} = {\color{#f87171}1}\!\cdot\!{\color{#34d399}1} + {\color{#f87171}2}\!\cdot\!{\color{#34d399}0} + {\color{#f87171}3}\!\cdot\!{\color{#34d399}1} = {\color{#fbbf24}4} \]

Her hücre = soldaki satır · sağdaki sütun (nokta çarpım). Aynı mantık matris-vektörde de geçerli.

Normlar

Bir Vektörün Büyüklüğü

\[ \|\mathbf{x}\|_2 = \sqrt{\sum_i x_i^2}, \qquad \|\mathbf{x}\|_1 = \sum_i |x_i| \] 
torch.norm(u)               # L2  (Öklid uzunluğu)
torch.abs(u).sum()          # L1  (mutlak değer toplamı)
torch.norm(torch.ones(4, 9))   # Frobenius (matris için L2)

Örn: \( \|[3,4]\|_2=\sqrt{9+16}=5 \) (3-4-5 üçgeni), \( \|[3,4]\|_1=7 \). Matris için Frobenius \( \|\mathbf{A}\|_F \).

Öğrenmede hata ve regularization normla ölçülür; L1 seyreklik sever.

Etkileşimli · Türev

Türev = Anlık Değişim

\( f'(x)=\lim_{h\to 0}\dfrac{f(x+h)-f(x)}{h} \)
\( f(x)=x^2 \Rightarrow f'(x)=2x \)
x1.5
f(x)2.25
eğim f'(x)3.00

Eğim = "x'i artırırsam f ne olur". Teğetin eğimi = türev. Kaydırıcıyı oynat!

Gradyan

Çok Değişken: Kısmi Türev & Gradyan

\[ f(x_1,x_2)=x_1^2 + 2x_2^2 \;\Rightarrow\; \nabla f = \big[\,2x_1,\ 4x_2\,\big]^\top \]

Kısmi türev

Diğer değişkenleri sabit tut, birine göre türet: \( \partial f/\partial x_i \).

Gradyan ∇f

Tüm kısmi türevlerin vektörü; en dik çıkış yönü.

Öğrenme, ∇f'in tersine küçük adım atar (gradyan inişi). Bir ağda milyonlarca kısmi türev → autograd (öğrenme haftası).

Zincir Kuralı

İç İçe Fonksiyonların Türevi

\[ y=f(g(x)) \;\Rightarrow\; \frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx} \]
\( y=(3x+1)^2 \Rightarrow \frac{dy}{dx}=2(3x+1)\cdot 3 \)

Türevleri çarparak geriye taşırsın — zincir kuralı geri yayılımın kalbi. (Autograd: öğrenme haftası.)

Genelleme Açığı

\[ E_{\text{gerçek}} = \mathbb{E}_{(\mathbf{x},d)\sim p}\big[\ell(y(\mathbf{x}), d)\big] \;\approx\; E_{\text{test}} = \frac{1}{m}\sum_{j=1}^{m} \ell\big(y(\mathbf{x}'_j), d'_j\big), \qquad \text{açık} = E_{\text{test}} - E_{\text{eğitim}} \]

🔈 okunuş: 𝔼 “beklenen değer”: verinin geldiği dağılımdaki bütün (x, d) çiftleri üzerinden ortalama·p veriyi üreten dağılım·x′ “x üssü”: hiç görülmemiş nokta

Eksik ve Aşırı Öğrenme

🔈 okunuş: ȳ “y bar”: başka eğitim kümeleriyle eğitilmiş ağların ortalaması·f gerçek kural

λ noktalar

N = 32, 16000 epoch, kayba λ/2·‖W‖² eklendi (bias'lar hariç, H5'teki gibi). Az λ ezberi frenliyor; fazlası ağı “bilmiyorum”a itiyor.

Türetme

Neden İşe Yarıyor?

\[ E_\lambda = E + \frac{\lambda}{2}\lVert W\rVert^2 \;\Rightarrow\; \frac{\partial E_\lambda}{\partial w} = \frac{\partial E}{\partial w} + \lambda w \;\Rightarrow\; w \leftarrow \underbrace{(1 - \eta\lambda)}_{\text{sönüm}}\,w - \eta\,\frac{\partial E}{\partial w} \]

🔈 okunuş: λ “lambda”: ceza katsayısı (H5'te α; momentumla karışmasın)·‖W‖² ağırlık kareleri toplamı, bias hariç

🧲 Her adımda sönüm

η = 2, λ = 0.0001: her epoch ağırlık 0.9998 ile çarpılır. Veri itmeyen ağırlık sıfıra doğru erir.

⏱️ Erken durdurma da benzer

import copy, torch, torch.nn as nn
from torch.nn.functional import binary_cross_entropy_with_logits as bce
from sklearn.metrics import confusion_matrix, roc_auc_score
torch.set_default_dtype(torch.float64); torch.manual_seed(1)
X = (torch.rand(1300, 2) * 2 - 1).round(decimals=2)
d = (X.norm(dim=1) < 0.7).double()
ters = torch.rand(1300) < 0.1; d[ters] = 1 - d[ters]            # %10 etiket gürültüsü
Xtr, dtr, Xva, dva, Xte, dte = X[:100], d[:100], X[100:300], d[100:300], X[300:], d[300:]
torch.manual_seed(0)
ag = nn.Sequential(nn.Linear(2, 32), nn.Sigmoid(), nn.Linear(32, 1))
opt = torch.optim.SGD(ag.parameters(), lr=2.0)                 # toplu GD: epoch başına 1 adım
en_iyi, sabir = (float('inf'), 0, None), 1000
for epoch in range(1, 16001):
    opt.zero_grad(); bce(ag(Xtr).squeeze(1), dtr).backward(); opt.step()
    with torch.no_grad(): v = bce(ag(Xva).squeeze(1), dva).item()   # doğrulama: yalnız ölç
    if v < en_iyi[0]: en_iyi = (v, epoch, copy.deepcopy(ag.state_dict()))
    elif epoch - en_iyi[1] >= sabir: break                      # 1000 epoch iyileşme yok
ag.load_state_dict(en_iyi[2]); p = torch.sigmoid(ag(Xte).squeeze(1)).detach()
print(epoch, en_iyi[1], round(en_iyi[0], 4))                    # 1732 732 0.3709
print(((p >= 0.5).double() == dte).double().mean().item())      # 0.846
print(confusion_matrix(dte, p >= 0.5).tolist(), round(roc_auc_score(dte, p), 4))

Çapraz Doğrulama, Kodda

import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import confusion_matrix, roc_auc_score
iris = load_iris().data[:, 2:]                                   # petal uzunluğu, genişliği
X = np.empty((100, 2)); X[0::2] = iris[50:100]; X[1::2] = iris[100:]   # dönüşümlü (H4)
d = np.tile([0., 1.], 50)                                        # 0 versicolor, 1 virginica
p, hata = np.zeros(100), []
for tr, te in StratifiedKFold(5, shuffle=True, random_state=0).split(X, d):
    mu, sd = X[tr].mean(0), X[tr].std(0)                         # ölçek YALNIZ eğitim katından
    Z = (X - mu) / sd; w = np.zeros(2); b = 0.0
    for epoch in range(200):                                     # H5'in sürekli perceptronu
        for i in tr:
            y = 1 / (1 + np.exp(-(w @ Z[i] + b)))
            w += 0.1 * (d[i] - y) * Z[i]; b += 0.1 * (d[i] - y)
    p[te] = 1 / (1 + np.exp(-(Z[te] @ w + b)))                    # katman dışı olasılık
    hata.append(int(np.sum((p[te] >= 0.5) != (d[te] == 1))))
print(hata, sum(hata))                                           # [2, 1, 0, 0, 3] 6
print(confusion_matrix(d, p >= 0.5).tolist(), round(roc_auc_score(d, p), 4))
# [[47, 3], [3, 47]] 0.99

Toplam 6 hata: H5'in aynı veride saydığı 6 ile aynı. Üç parametreli doğrusal model ezberleyemez; açık ≈ 0. Kapasite düşükken eğitim hatası dürüst bir tahmin, yüksekken değil (Slayt 7).

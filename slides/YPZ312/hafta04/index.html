Hatırla · Hafta 3

İki Sorun, Bir Kural

🙈 Sorun 1 · Basamak kör

Delta: Δw = η(d − y)·f′(net)·x. Basamakta f′ = 0 → Δw hep 0: nöron hiç öğrenmez.

🔁 Sorun 2 · Doğruyken de iter

Widrow–Hoff: r = d − net. 4/4 doğru olsa bile d − net ≠ 0 → w değişmeye devam eder.

\[ \Delta\mathbf{w} = \eta\,\underbrace{(d - y)}_{\text{doğruysa } 0}\,\mathbf{x}, \qquad y = \operatorname{sgn}(\mathbf{w}^\top\mathbf{x} + b) \]

✅ f′ yok: türev hiç gerekmez → basamakla çalışır.

✅ Doğruysa d − y = 0: w kendiliğinden durur.

Bedeli: garanti yalnız doğrusal ayrılabilir problemlerde. Bu haftanın hikâyesi bu →

Model

Ayrık Perceptron

\[ y = \operatorname{sgn}(\text{net}) = \begin{cases} +1, & \text{net} \ge 0 \\ -1, & \text{net} < 0 \end{cases} \qquad \text{net} = \mathbf{w}^\top\mathbf{x} + b \]

🔢 “Ayrık” ne demek?

Çıktı yalnız iki değer alır: ±1 (bipolar) ya da 0/1 (unipolar). Arası yok. H5'te aynı yapı f = σ ile: sürekli perceptron.

⚖️ net = 0 ise?

Nokta tam sınırın üstünde. Bu derste sgn(0) = +1 kabul ediyoruz (H3 animasyonlarındaki gibi).

🧮 Bias yine içeride

x = (x₁, …, xₙ, 1), w = (w₁, …, wₙ, b) → net = wᵀx. Sondaki 1 bias girişi (H3).

Geometri · Hafta 2'den Bir Adım Öte

net Aslında Bir Uzaklık

Hafta 2: bir nöron = bir karar doğrusu (w doğruya dik, b kaydırır). Bugün bir adım öte: net sayısı neyi ölçüyor?

\[ \underbrace{\frac{\mathbf{w}^\top\mathbf{x} + b}{\|\mathbf{w}\|}}_{\text{x'in sınıra işaretli uzaklığı}} \qquad\Longrightarrow\qquad \text{net} = \|\mathbf{w}\| \times \text{uzaklık} \]

🔈 okunuş: ‖w‖ “w'nin normu”: uzunluğu, √(w₁² + w₂²); H3'te |w| yazdık·⟂ “diktir”

📐 w ⟂ sınır

Sınırdan iki nokta p, q: wᵀp + b = 0 = wᵀq + b ⇒ wᵀ(p − q) = 0. Yani w, sınır boyunca her yöne dik.

➕➖ İşaret = taraf

net > 0: w'nin gösterdiği taraf (+1). |net| büyüdükçe nokta sınırdan uzaklaşır.

🔍 Ölçek serbest

w ve b'yi 2 ile çarp: sınır aynı, net 2 katı. sgn ölçeğe bakmaz: karar değişmez.

Son gözlem, perceptron'da η'nın neden önemsiz olabildiğini açıklayacak (Slayt 14). Önce elle deneyelim →

H3'teki kalıp: Δw = η·r·x. Perceptron'da r = d − y: Widrow–Hoff'un d − net'i yerine basamaklı çıktı. Türetilmedi, Rosenblatt'ın sezgisi; ama yakınsaması kanıtlı (Slayt 19).

Etkileşimli · Sezgi

Güncelleme w'yi Döndürür

● +1 · ○ −1 · kırmızı halka = yanlış · pembe ok = d·x · kesikli = önceki w

\[ (\mathbf{w} + \eta\,(d - y)\,\mathbf{x})^\top\mathbf{x} = \mathbf{w}^\top\mathbf{x} + \eta\,(d - y)\,\|\mathbf{x}\|^2 \]

Sadelik için bias yok (sınır orijinden geçer), η = 0.5 → yanlışta w ← w + d·x. Her düzeltme o örneğin net'ini doğru yöne ‖x‖² kadar iter; ama başka bir örneği bozabilir → bu yüzden epoch'larca döneriz.

Algoritma

Perceptron Eğitimi: Ne Zaman Durur?

w = sıfır_vektör()               # ya da küçük rastgele
for epoch in range(max_epoch):    # güvenlik sınırı
    hata = 0
    for x, d in veri:             # x'in sonunda 1 → bias dahil
        y = sgn(w @ x)
        if y != d:                # yalnız yanılınca
            w = w + eta * (d - y) * x
            hata += 1
    if hata == 0: break           # bir tur hatasız → DUR

⏹️ Kendiliğinden durur

Hatasız bir epoch'ta Δw = 0: devam etmenin anlamı yok. Widrow–Hoff'ta durma kriterini biz seçiyorduk (E < ε ya da N epoch).

⏳ max_epoch neden?

Veri ayrılamıyorsa “hatasız tur” hiç gelmez → sonsuz döngü. Sınır koymak şart (Slayt 18).

🧾 En yalın hâli

Yanlışta d − y = 2d olduğundan Δw = 2η·d·x. η = 1/2 ile ders kitaplarındaki biçim: w ← w + d·x.

Perceptron'un bedeli: “en iyi” sınırı değil, ilk bulduğu ayırıcı sınırı verir; sınır bir örneğe çok yakın geçebilir (marj: Slayt 21).

Tanım

Doğrusal Ayrılabilirlik

\[ \exists\, \mathbf{w}, b:\qquad d_i\,(\mathbf{w}^\top\mathbf{x}_i + b) > 0 \qquad \forall i \]

🔈 okunuş: ∃ “vardır” (en az bir tane)·∀ “her … için”·dᵢ “d i”: i. örneğin hedefi

✳️ d·net > 0 hilesi

d = +1 ise net > 0, d = −1 ise net < 0 olmalı. İki koşul tek eşitsizlikte: doğru taraf.

📏 Her boyutta

2 girdide doğru, 3'te düzlem, n'de hiperdüzlem (H2). Tanım değişmez: uzayı ikiye bölen bir w, b var mı?

🔢 İki girdili mantık

16 olası mantık fonksiyonunun 14'ü ayrılabilir; yalnız XOR ve XNOR değil.

Hafta 2'de XOR'u kaba kuvvetle denemiştik: 15.625 kombinasyonun en iyisi 3/4. Şimdi bunun şans değil, zorunluluk olduğunu kanıtlayalım →

İspat

XOR Neden İmkânsız?

0/1 girdiler, y = 1 ⇔ net ≥ 0. XOR'u veren w₁, w₂, b olsaydı dört koşul aynı anda sağlanmalıydı:

girdiXORkoşul
(0, 0)0b < 0(1)
(1, 1)0w₁ + w₂ + b < 0(2)
(1, 0)1w₁ + b ≥ 0(3)
(0, 1)1w₂ + b ≥ 0(4)
\[ (3) + (4):\quad w_1 + w_2 + 2b \;\ge\; 0 \] \[ (1)\text{'den } -b > 0 \;\Rightarrow\; w_1 + w_2 + b \;\ge\; -b \;>\; 0 \] \[ \text{ama (2): } w_1 + w_2 + b < 0 \;\Rightarrow\; \text{çelişki!} \]

Hiçbir w₁, w₂, b XOR'u veremez. ∎ Hafta 2'deki 3/4 tavanı şanssızlık değil, matematik.

● hedef +1 · ○ hedef −1 · sarı halka = sıradaki · kırmızı halka = yanlış · kesikli = önceki doğru

Bipolar XOR, aynı ayarlar (η = 0.5, w₀ = 0). 4 adım sonra w yine [0, 0, 0]: aynı dört adım sonsuza kadar tekrar eder. Ayrılamayan veride perceptron hiç durmaz → max_epoch şart.

Teorem · 1962

Perceptron Yakınsama Teoremi

\[ \|\mathbf{x}_i\| \le R \;\;\text{ve}\;\; \exists\,\mathbf{w}^*\ (\|\mathbf{w}^*\| = 1):\;\; d_i\,\mathbf{w}^{*\top}\mathbf{x}_i \ge \gamma > 0 \] \[ \Longrightarrow\quad \text{güncelleme sayısı} \;\le\; \left(\frac{R}{\gamma}\right)^{2} \]

🔈 okunuş: γ “gama”: marj·w* “w yıldız”: ideal ayırıcı·R: en uzun girdi

📏 R

En uzun girdinin boyu; bias girişi 1 dahil: x = (x₁, x₂, 1).

↔️ γ (marj)

İdeal sınırın en yakın örneğe uzaklığı: sınıflar arası boşluk.

✅ Sonuç

Ayrılabilirse sonlu sayıda güncellemede durur; η'dan bağımsız (w₀ = 0).

İspat Taslağı

İki Eşitsizlik, Bir Sınır

η = 1 alalım (w₀ = 0 iken η yalnız ölçek). k. hatada w ← w + d·x; hata anında d·wᵀx ≤ 0 (yanlış taraf).

① Hizalanma
k ile büyür

\[ \mathbf{w}^{*\top}\mathbf{w}_k = \mathbf{w}^{*\top}\mathbf{w}_{k-1} + \underbrace{d\,\mathbf{w}^{*\top}\mathbf{x}}_{\ge\, \gamma} \;\Rightarrow\; \mathbf{w}^{*\top}\mathbf{w}_k \ge k\,\gamma \]

Her hata w'yi w*'ın yönüne en az γ yaklaştırır.

② Uzunluk
√k ile büyür

\[ \|\mathbf{w}_k\|^2 = \|\mathbf{w}_{k-1}\|^2 + \underbrace{2d\,\mathbf{w}_{k-1}^\top\mathbf{x}}_{\le\, 0} + \underbrace{\|\mathbf{x}\|^2}_{\le\, R^2} \;\Rightarrow\; \|\mathbf{w}_k\|^2 \le k\,R^2 \]

Hata anında orta terim ≤ 0: w'nin boyu yavaş uzar.

③ Birleştir

\[ k\,\gamma \;\le\; \mathbf{w}^{*\top}\mathbf{w}_k \;\le\; \|\mathbf{w}_k\| \;\le\; \sqrt{k}\,R \;\;\Rightarrow\;\; k \le \left(\frac{R}{\gamma}\right)^{2} \]

Orta adım: iki vektörün çarpımı boylarının çarpımını aşamaz (‖w*‖ = 1).

Sezgi: w, w*'a doğrusal hızla yaklaşırken boyu yalnız karekök hızla uzuyor. İkisinin oranı (aradaki açının kosinüsü) 1'i aşamayacağı için hata sayısı sınırlı.

Koda Dök

Perceptron, Sıfırdan

import torch
from sklearn.datasets import load_iris
iris = load_iris()
X = torch.tensor(iris.data[:100, [0, 2]], dtype=torch.float32)  # sepal ve petal uzunluğu (cm)
d = torch.tensor([-1.] * 50 + [1.] * 50)                         # setosa −1, versicolor +1
w, b, eta = torch.zeros(2), torch.tensor(0.), 0.1

for epoch in range(1, 21):                       # max_epoch = 20
    hata = 0
    for x, t in zip(X, d):
        y = 1. if w @ x + b >= 0 else -1.        # sgn(0) = +1
        if y != t:                               # yalnız yanılınca
            w = w + eta * (t - y) * x
            b = b + eta * (t - y)
            hata += 1
    print(epoch, hata)
    if hata == 0: break                          # bir tur hatasız → DUR
# 1 2 | 2 2 | 3 3 | 4 2 | 5 1 | 6 0
print(w, b)       # tensor([-0.6800,  1.8200]) tensor(-0.4000)

✅ Rosenblatt (1958): ağırlıklarını örneklerden ayarlayan ilk makine

✅ Model: y = sgn(wᵀx + b); net = ‖w‖ × sınıra işaretli uzaklık

Perceptron'u Kendin Kodla

1 · OR'u elle çalıştır. Bipolar OR, w₀ = 0, η = 0.5. Hangi adımlarda güncelleme oldu? Sonunda w = [1, 1, 1] çıkmalı (3 güncelleme).

2 · XOR döngüsü. Slayt 26'deki kodu bipolar XOR'a uyarla; her adımda w'yi yazdır. Kaçıncı adımda w = [0, 0, 0]'a döndü?

3 · η deneyi. AND'de w₀ = 0 ve w₀ = [0.5, −0.3, 0.2] için η = 0.1, 1, 5 dene. Güncelleme sayıları neden yalnız birinde hep aynı?

4 · Iris + pocket. Versicolor/virginica (petal ölçüleri) için cepli perceptron yaz. Sıralı ve karıştırılmış veride cepteki hatayı karşılaştır.

İpucu: XOR için X = [[1, 1], [1, −1], [−1, 1], [−1, −1]], d = [−1, 1, 1, −1].

Hafta 5 — Sürekli Perceptron

Basamağın yerine σ: çıktı artık 0–1 arası bir “güven”. Delta kuralı sınıflandırmaya döner; ayrılamayan veride de anlamlı bir en iyi tanımlanır. Hâlâ tek katman; çok katmana H6'da, geri yayılıma H7'de geçeceğiz.
